# MML-SDG2-ZERO-HUNGER
🌾 Zero Hunger — Crop Yield Prediction using Machine Learning

A Machine Learning project aligned with UN Sustainable Development Goal (SDG) 2: Zero Hunger.
This project predicts crop yield for smallholder farmers using fertilizer usage coefficients and environmental features, supporting data-driven agricultural decision-making.

📘 Project Overview

Agriculture remains the backbone of food security in Africa, yet millions of smallholder farmers face unpredictable crop yields due to poor data use, low soil management, and climate change.

This project demonstrates how AI and data science can empower farmers and policymakers to make informed decisions to reduce hunger and increase food productivity.

🎯 Objectives

Predict crop yield based on key agricultural inputs (fertilizer coefficients A, B, and C).

Support smallholder farmers with data-driven insights.

Demonstrate how AI can be used to achieve SDG 2 — Zero Hunger.

🧠 Technologies Used

Python (Pandas, NumPy, Scikit-learn, Matplotlib)

Machine Learning Models: Linear Regression, Random Forest

Visualization: Matplotlib for performance and prediction plots
